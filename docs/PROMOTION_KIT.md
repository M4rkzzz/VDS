## 一句话介绍

VDS 是一个可自部署的屏幕共享和 relay 工具，面向觉得 Oopz / QQ / KOOK / Discord 屏幕分享不够可控的场景，支持 native 采集、OBS 接入、多人观看、链式转发和浏览器观看。

## 30 秒介绍

VDS 是一套偏工程实用的私有屏幕共享系统。房主可以共享屏幕、窗口或 OBS 推流，观看者可以用桌面客户端或浏览器加入。它不是聊天软件，也不是会议套件，重点是把“开播、发房间号、多人观看、链式 relay、OBS 接入、局域网手机观看”这条链路做得清楚可控。

如果你在 Oopz、QQ、KOOK、Discord 的屏幕分享里遇到过画质、人数、局域网、OBS 接入、自部署或诊断不可控的问题，VDS 可以作为一个更专业的替代方案来试。

GitHub：<https://github.com/M4rkzzz/VDS>

## 适合发到开发者社区的版本

我做了一个开源屏幕共享工具 VDS，定位是 Oopz / QQ / KOOK / Discord 屏幕分享的可自部署替代品。

它主要解决几个问题：

- 房主共享屏幕、窗口或 OBS 推流。
- 多观看端加入时优先链式 relay，减少房主上行压力。
- 支持桌面客户端和浏览器观看端。
- 支持局域网手机浏览器 HTTP 测试。
- 有 3010 后台实时看房间拓扑、节点状态和 media manifest。
- 有较完整的 P2P、采集、编码、WebCodecs、relay 诊断。

项目地址：<https://github.com/M4rkzzz/VDS>
最新版 Release：<https://github.com/M4rkzzz/VDS/releases/tag/v1.7.1>

## 适合发到 Reddit / Hacker News / 英文社区的版本

VDS is a self-hostable screen sharing and relay tool for people who want more control than typical chat-app screen sharing.

It supports native Windows capture, local OBS ingest, multiple viewers, chained relay to reduce host uplink pressure, browser viewers, LAN mobile browser testing, and a live topology/admin dashboard.

It is not trying to be another chat or meeting app. The goal is a practical, inspectable screen-sharing path for demos, debugging, LAN sessions, and small-team collaboration.

GitHub: <https://github.com/M4rkzzz/VDS>
Release: <https://github.com/M4rkzzz/VDS/releases/tag/v1.7.1>
